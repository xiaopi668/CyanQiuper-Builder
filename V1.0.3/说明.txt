CyanQiuper V1.0.3
=================

这个文件夹里是 V1.0.3 的完整新版本，电脑版和安卓版都在里面。

目录
----
电脑版\        电脑上用的版本（解压或直接进目录用）
电脑版.zip     电脑版的压缩包（方便拷贝/上传）
安卓版\        手机 APK（arm64 手机用 arm64 那个）
更新日志.txt   V1.0.3 更新内容


电脑版怎么用
------------
1. 进「电脑版」文件夹
2. 第一次：双击「安装依赖.bat」（装 node_modules，只需一次）
3. 以后：双击「start.bat」
   · 网页控制台：http://127.0.0.1:11452
   · WS 服务：ws://127.0.0.1:11451
   · 游戏内：/connect ws://127.0.0.1:11451
4. 网易版相关：控制台 →「网易版」页
   · 上方新增「网络账号信息」：填登录渠道、账号（邮箱/手机号）、密码、备注 → 保存账号
   · 下面仍是「进服配置」（房间号/密码等）


安卓版怎么用
------------
1. 把 CyanQiuper-v1.0.3-arm64-v8a.apk 传到手机安装（允许未知来源）
2. 打开 APP，等几秒，会自动用浏览器打开控制台
3. 游戏内：/connect ws://127.0.0.1:11451
4. 网易版账号同样在「网易版 → 网络账号信息」里配置，保存在手机本机
详见 安卓版\安装说明.txt


V1.0.3 主要变化
---------------
· 新增：网络账号信息配置（电脑版 + 安卓版都有）
· 新增：安卓版 APK（内置 Node 运行时和全部依赖，装上即用）
· 安卓版内置了网易版服务，手机端也能用网易版面板和账号配置
· 版本号统一到 1.0.3（页脚显示 v1.0.3，APK versionCode 3）
