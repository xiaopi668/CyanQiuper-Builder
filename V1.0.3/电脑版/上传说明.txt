CyanQiuper 交付包 · 使用与上传说明
====================================

本目录 = 仓库根目录结构（平铺），所以有两种用法：

【本地运行】
  1. 第一次：双击 安装依赖.bat（安装 node_modules，只需一次）
  2. 以后：双击 start.bat 启动控制台
     - 网页管理 : http://127.0.0.1:11452
     - WS 服务  : ws://127.0.0.1:11451
     - 游戏内   : /connect ws://127.0.0.1:11451
  注意：不要在子目录里启动（旧结构 server\ 已取消）

【上传 GitHub】
  把本目录的文件按同名覆盖到仓库对应位置：
    main.ts / admin-server.ts / cli.mjs / start.bat / package.json ...  -> 仓库根
    admin\  -> 仓库 admin\
    src\    -> 仓库 src\
    docs\   -> 仓库根或 docs\
  不要上传：admin\auth.json（口令哈希）、node_modules\、logs\、qiuper-cli.json、截图
