CyanQiuper 更新日志
===================

V1.0.3（2026-11-08）
--------------------
新增
· 网易版「网络账号信息」配置（电脑版 + 安卓版）
  - 字段：登录渠道（官方 / 渠道服 / 令牌）、账号（邮箱或手机号）、密码、备注
  - 只保存在本机：netease-account.json（文件权限 600），接口只返回掩码
  - 网易版状态行会显示「账号 zb***t@163.com」
  - 支持保存、清除、显示/隐藏密码；服务未启动时用本地缓存回显
· 安卓版 APK（V1.0.3 首次发布）
  - 内置 Node.js 运行时（nodejs-mobile libnode）+ 全部依赖，无需 Termux / npm
  - 首次启动释放运行文件（约 5~15 秒），之后秒开
  - 自动用浏览器打开控制台 http://127.0.0.1:11452
  - 内置 WS 服务、管理端、网易版服务（三者在同一进程内）
  - 前台常驻通知保活

修复 / 优化
· 安卓端补齐网易版服务，`/api/netease/*` 在手机上可用
· 控制台页脚显示版本号 v1.0.3
· package.json 版本号更新到 1.0.3

接口
· GET    /api/netease/account   读取账号（脱敏）
· POST   /api/netease/account   保存账号（channel/account/password/note）
· DELETE /api/netease/account   清除账号
