CyanQiuper 安卓版 V1.0.3 · 安装说明
=====================================

一句话
------
装一个 APK 就能在手机上用 Qiuper：Node 运行时和全部依赖都内置，不用 Termux、不用连
电脑、不用 npm install；打开后自动用浏览器打开控制台。


安装
----
1. 把 CyanQiuper-v1.0.3-arm64-v8a.apk 传到手机
2. 点开安装（提示未知来源就允许）
3. 桌面出现 CyanQiuper 图标


第一次打开
----------
1. 点图标 → "正在释放运行文件…"（约 5~15 秒，只需一次）
2. 自动启动服务 → 状态"服务已启动"
3. 自动用浏览器打开控制台 http://127.0.0.1:11452
   （没跳就点 APP 里的「打开控制台」）
4. 网易版账号配置：控制台 →「网易版」→ 上方「网络账号信息」
   填 登录渠道 / 账号（邮箱或手机号）/ 密码 / 备注 →「保存账号」
   账号只保存在手机本机，页面只显示掩码
5. 回到 Minecraft：/connect ws://127.0.0.1:11451


日常使用
--------
· 用之前先打开 APP（服务随之启动），再去浏览器/游戏
· 关浏览器不影响服务；但不要把 APP 从后台划掉（通知栏常驻通知要保留）
· 手机省电设置里给 CyanQiuper 开"允许后台运行/自启动"
· 端口：控制台 11452，WS 11451，控制接口 11453，网易版 11454（都在手机本机）


系统要求
--------
· Android 7.0 及以上
· CPU：arm64-v8a（绝大多数手机）
· 内存 1 GB 以上（推荐 2 GB）
· 可用存储约 90 MB
· 一个能正常打开 http 网页的浏览器
· x86_64 那个 APK 只给安卓模拟器/极少数设备用

它怎么做到"自动装依赖"
----------------------
· nodejs-mobile 的 libnode.so 把 Node.js 18 打进 APK
· esbuild 把 WS 服务、管理端、结构解析、网易版服务打包成单个 app.cjs
  （mcpews、ws、voxel-geometry 全部内联）
· 首次启动把 app.cjs 和 admin 页面释放到
  /data/data/com.cyan.qiuper/files/qiuper/，再由内嵌 Node 运行
· 所以完全离线可用，不需要 npm、不需要网络、不依赖 Termux

已知限制
--------
· 控制台是桌面布局，手机上字偏小，可双指缩放/横屏
· 首次启动释放文件需要几秒
· 手机和游戏必须在同一台设备上（WS 服务在手机本地）
· 导入大结构时保持 Qiuper 在前台，避免被系统回收
